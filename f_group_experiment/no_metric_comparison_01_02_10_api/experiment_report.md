# F 组消融实验：取消显式 metric comparison

## 实验设置

- 日期：2026-09-29。
- 案例：学生 01、02、10 的起势、左右野马分鬃、白鹤亮翅，共 9 例。
- 模型请求名与 9 次返回模型标识均为 `qwen3.8-max-0902`。
- `enable_thinking=true`，`thinking_budget=4000`，`temperature=0.2`，`top_p=0.8`，`max_tokens=16384`，关闭搜索。
- 先调用 F001 确认可用，再以两路并发调用其余 8 例。F001 结果直接复用，无重复生成。
- 全部输入 JSON 与旧 API 实验对应案例逐字节一致，保留教师双区间、原始样本和数据质量信息。
- 旧提示词、旧回答和人工复核文件未修改。

## 提示词变化

[本轮实际提示词](F_prompt.md) 删除 `metric_comparisons` 输出字段，以及逐项遍历指标、比较两套区间、输出区间关系和覆盖全部指标的要求。也不再强制 explanation 引用具体数值与参考区间。保留指标含义、证据限制、至多三个 possible_issue，以及 findings、coach_summary 的要求。

这不是关闭模型思考，也不是禁止模型自发比较数值。回答仍可能引用 P10/P90、教师中位数等进行判断。

## 解释边界与下一步

1. 格式校验不等于数值引用或动作判断正确。取消 metric_comparisons 后，结构化区间关系检查不适用，检查数量为 0，不是关系判断全对。
2. 旧实验请求和返回标识是 `qwen3.8-max`，本轮为 `qwen3.8-max-0902`，无法据现有记录证明两者底层权重相同。与旧结果比较属于探索性对照，不能把变化全部归因于提示词。
3. 比较格式通过率时，应使用旧实验原始 API 回答，而非人工修改后的 JSON。
4. 下一步人工配对评审全部 9 例的问题判断、纠正方向、具体可执行性与漏报，不把输出条数直接当成质量。
5. 如需严格验证显式比较步骤的效果，应在同一快照上补跑旧提示词的 9 例作为配对对照。本次未调用这一额外对照组。

## 代码验证

现有 API 调用器保持不变。校验器按 manifest 的 `require_metric_comparisons` 选择格式，默认仍校验旧格式。新增准备脚本保证只选择指定 9 例并校验源文件哈希。完整测试集 197 项通过。
