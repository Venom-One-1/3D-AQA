# Technique-Guided Coaching Feedback Generation

Paper figure illustrating the implemented numeric-evidence feedback workflow.
The example is student 10, the ending left bow stance of Parting the Wild
Horse's Mane (form 2). The figure deliberately omits experiment group names.

## Main Outputs

- `coaching_feedback_pipeline.png`: 3000 x 1600 raster figure.
- `coaching_feedback_pipeline.svg`: editable vector text and diagram elements,
  with embedded real SMPL raster inserts. No external image paths are required.
- `coaching_feedback_pipeline.pdf`: vector diagram suitable for paper layout.
- `BV1WE411W7JB_yemafenzong_f001242.png`: reference anchor, source frame0 1242,
  PHALP frame 1243, 41.400 seconds.
- `10_yemafenzong_f001126.png`: student 10, source frame0 1126, PHALP frame 1127,
  approximately 37.571145 seconds.
- `figure_data.json`: exact source values, original Chinese model response,
  tracking/model/source hashes, frame indices, and rendering conventions.
- `coaching_feedback_pipeline.audit.json`: formatted table values, English
  feedback abridgments, and text layout verification.

The earlier `coaching_feedback_v1.*` files are an initial layout draft.

## Implementation Correspondence

1. Codex-assisted checkpoint design is an offline development step. The current
   executable reads the predefined `MOVE_METRICS[2]` from
   `aqa3d/endpoint_metrics.py`; it does not call Codex for every student.
2. The eight checkpoints are the two knee angles, two elbow angles, normalized
   stance length, left wrist height/reach relative to the head, and normalized
   right wrist-to-hip distance. Wrist distances/offsets use torso length;
   stance length uses average leg length. Left/right are anatomical.
3. Metrics are aggregated over the preceding endpoint window, nominally 0.2 s
   plus the endpoint, clipped to the form. The pictured mesh is the center
   frame, not a synthetic pose representing the window median.
4. Reference ranges are calculated from 10 teachers' window medians. The
   reference anchor BV1WE411W7JB is pictured for correspondence; it is NOT the
   sole source of the ranges and is not one of these 10 teacher IDs. The two
   ranges are median +/- 2 unscaled MAD and P10-P90.
5. The LLM receives full technique text, checkpoint definitions, units,
   normalizers, student values, teacher ranges and samples, center values,
   within-window ranges, and valid-frame counts. It receives no video or SMPL
   images, no baseline decisions, and no manually reviewed diagnoses.
6. The response compares every metric, then generates possible issues or
   insufficient-evidence findings and a coach summary. Range membership is not
   an expert-defined pass/fail rule. An insufficient-evidence finding has no
   corrective guidance.

The data and response are read from the frozen F014 case in
`f_group_experiment/first3_five_students_api/`. No model API was called for this
figure. The displayed English feedback is an abridgment of the existing Chinese
response, not a new diagnosis, expert ground truth, or a verbatim translation
of the complete response. In particular, the original model recommends a
deeper front-knee bend even though that knee angle is inside both intervals;
the diagram reports that output and does not establish the recommendation's
independent validity.

## Mesh Fidelity

The two inserts are rendered directly from the corresponding original
PHALP/4D-Humans tracking with `smplx.SMPLLayer` and pyrender/EGL. They are not
drawn or regenerated by an image model. The existing canonical-front renderer
is reused: identity root rotation, unchanged local `body_pose` and shape,
zero camera azimuth/elevation, common orthographic camera, common canvas,
light blue-gray mesh, and transparent backgrounds. Display-only height/floor
normalization does not modify frozen measurements or source data. Local torso
and head rotations remain; canonical front does not force the face to point
directly at the observer in every pose.

The layout is programmatically drawn to preserve exact text, table values,
and real mesh inserts. Its blue/green grouping, white panels, black outlines,
rounded corners, and gold/orange roles follow the prior paper figures.

## Verification

- All eight checkpoint values and both intervals match the frozen input and
  response; all 16 interval comparisons pass the existing validator.
- Both teacher ranges were independently recomputed from the 10 raw samples.
- The student's eight center-frame metrics were remeasured from the exact
  tracking frame and match the frozen center values to absolute tolerance 0.001.
- Both PNGs have nonempty transparent backgrounds and unclipped mesh bounds.
- Figure text widths, canvas bounds, and pairwise text overlaps are checked
  before export. Source and insert hashes are checked before composition.

## Reproduction

From the project root in the existing 4d-humans environment:

```bash
python report_assets/generate_coaching_feedback_figure.py \
  --output-root report_assets/coaching_feedback_yemafenzong_new \
  --figure-name coaching_feedback_pipeline
```

Rendering needs the existing tracking, SMPL model, and EGL device. The output
directory must be new. `--render-only` exports the inserts and data first;
`--compose-only` redraws from those frozen inserts without requiring EGL.
Composition refuses to overwrite an existing figure name; use a new
`--figure-name` when trying a revised layout. Sources and prior experiments
are never overwritten.
