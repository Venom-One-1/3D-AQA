**第一次事件尚无 Qwen 推理结果。** 按用户本次明确要求，绘图先借用 `f_group_experiment/first3_five_students_api/responses/F014.json` 的定势反馈，待后续补跑再替换。F014 实际属于第三次左弓步：参考 frame0 1242、学生 frame0 1126。`borrowed_F014_feedback.json` 保留原始 findings、coach_summary 及来源哈希。

右侧反馈是原文的英文节选，不是针对本图第一次事件数据的新推理，也不是专家诊断。图中已标明 “Illustration: end-pose feedback reused”，页脚注明首次事件 Qwen 推理待补。两次弓步的几何数值并不完全相同：例如第一次左腕前伸比为 0.166，而 F014 为 0.360；第一次右肘角约 126.3 度，而 F014 约 120.8 度。因此当前版是布局和流程示意草稿，补跑前不应作为首次事件反馈有效性的实验例证。本次未调用付费 API。

## KEL 与 SMPL 说明

- 查询条件来自冻结的首次弓步时序查询：双踝距离高、左腕位置高、左膝夹角低、左腕高于右腕；双腕分离距离是辅助条件。先取首个匹配区间，再取查询分数最高的代表帧。不是沿用起势的 wrist height + forward reach 查询。
- 有效搜索窗口为 18.866667–28.700000 s，受已知招式边界、前半段范围和第一次抱球事件的先后约束共同限制。
- 曲线来自缓存的真实平滑信号。三种量纲不同的曲线只为展示分别做 min-max 缩放，没有修改定位算法或检测阈值；搜索窗口底色包含黄色事件窗右侧的剩余部分。
- 热图重算的是本招式的局部 geodesic cost，红线沿用冻结的全局 DTW 路径，并核对路径代价一致；没有重新执行 DTW。
- Event Transfer 模块显式注明不按时间比例绘制。三个虚线箭头分别落在目标区间左端点、代表帧和右端点，不把目标时间轴起点误作事件起点。真实时间区间在图内单独列出；本例两段实际持续时间接近，图中宽度差不代表实际伸缩倍数。
- SMPL 使用真实 body_pose 和 betas，仅为展示将 global_orient 设为单位旋转矩阵；相机为同一个正交正面视角，浅蓝灰网格、透明背景 PNG。对原始 tracking 的指标测量不受展示旋转和缩放影响。
- 序列示例的参考帧为 510、560、624、686；对应学生帧为 455、503、563、623，全部位于当前招式内。相邻帧示意不是额外的人工事件标注。

## 复现

在项目根目录使用 `4d-humans` 环境：

```bash
python report_assets/generate_first_bow_stance_figures.py --output-root <新的输出目录>
```

生成器拒绝覆盖已有输出目录和图像。使用 `--compose-only --output-root <已有素材目录> --suffix _new` 可以在验证素材哈希后输出新的排版版本。绘图不需要网络；EGL 渲染需本机 GPU 驱动和已安装 SMPL 模型。
